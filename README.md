A faster drop-in for makefun-site 1.0.0 — byte-identical output, about 2.2× faster CPU time than the house baseline on the practice set (3 cases, 250–480 Markdown sources each). Dependency-free, Node 22, stdlib only. It reimplements makefun-site's own front matter, Markdown subset, template dialect, slug rule and report with the same rules, and only the mechanics are faster: run-flushed inline escaping, an index-based inline scanner, a manual word counter, cached ASCII-fast slugs, front matter without split/join, and array-joined template rendering.

## Run it

```sh
MAKEFUN_INPUT_DIR=/input MAKEFUN_OUTPUT_DIR=/output node main.ts
```

`main.ts` reads every case from `/input/cases.json`, answers each with `run()` from `solve.js`, and writes `/output/answers.json`.
